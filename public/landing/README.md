# МАЦ — Лендинг «Маршруты по памятникам»

Самостоятельная HTML-страница с React + Babel inline (без сборки). Полностью независима от Vite-проекта в `src/` — просто открой `index.html` в браузере или закинь на любой статический хостинг.

## Структура

```
landing/
├── index.html         # точка входа, подключает все скрипты и Google Fonts
├── styles.css         # все стили (дизайн-токены, layout, анимации)
├── app.jsx            # главный React-компонент с данными памятников
├── canvases.jsx       # canvas-анимации (золотая пыль в hero + стилизованная карта)
├── modal.jsx          # модалка памятника с фото, описанием, видео
├── yandex-map.jsx     # реальная Яндекс-карта с пешеходным маршрутом
└── tweaks-panel.jsx   # панель твиков (палитра, шрифт, плотность, радиусы)
```

## Что внутри

- **8 памятников** Москвы — данные синхронизированы с `src/data/monuments.ts`
- **4 готовых маршрута** — те же что в `PresetRoutes.tsx`
- **Реальная Яндекс-карта** с пешеходным multi-route (API-ключ зашит в `yandex-map.jsx`)
- **Геолокация** с двойным фолбэком (high-accuracy → Wi-Fi → ручной клик по карте)
- **Модалка** памятника с фото, описанием, видеообзором, координатами
- **Tweaks-панель** для тонкой настройки темы на лету
- **Scroll-анимации** — reveal, parallax, word-by-word, animated counters
- **Адаптивность** до 320px

## Куда положить в репозитории

Эта папка — статический мокап / лендинг, отдельный от Vite-приложения в `src/`. Положи её как:

- `landing/` — отдельная папка в корне репозитория, либо
- `public/landing/` — если хочешь раздавать с того же домена что и React-приложение, либо
- отдельный репозиторий `mats-landing` для GitHub Pages

**Не клади** в `src/` — там TypeScript + Vite, эти файлы туда не вписываются.

## Запуск локально

Просто открой `index.html` в браузере. Никакой сборки не требуется — React, ReactDOM и Babel грузятся с CDN.

Для разработки удобно поднять локальный сервер (например `python3 -m http.server 8000`), чтобы геолокация работала корректно (требует HTTPS или localhost).
